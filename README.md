# 音游开字母

一个简单、轻量的 AstrBot QQ 群音游开字母猜曲插件。

插件内部名：`astrbot_plugin_music_guess`

## 功能

- 每局随机抽取 8 首歌曲
- 隐藏 Unicode 字母（英文字母、中文汉字、日文假名等）和 ASCII 数字 0-9
- 支持开英文字母、数字与中文 / 日文等文字字符
- 支持按编号猜歌
- 猜完全部歌曲后自动结束
- 可主动结束并公布答案
- 每个 QQ 群游戏状态完全独立
- 不调用 LLM
- 不使用数据库
- 内置多份按音游分类的曲库（Phigros、Arcaea、maimai 等），可在 WebUI 勾选启用
- 无第三方 Python 依赖

## 支持环境

- AstrBot `>=4.27.3,<5`
- QQ 官方机器人（`qq_official`）

当前版本以 AstrBot `v4.27.3` 为主要开发和测试环境。

## 安装

### AstrBot WebUI

将本插件的 ZIP 包上传到 AstrBot WebUI 的插件管理页面安装。

### GitHub 仓库

仓库地址：

`https://github.com/Ice2974/astrbot_plugin_music_guess`

如果从源码手动安装，请确保插件目录最终为：

```text
data/plugins/astrbot_plugin_music_guess/
```

## 使用方法

所有游戏操作都需要先 @机器人。未 @机器人 的普通群消息不会触发本插件，也不会被本插件拦截。

开始：

```text
@机器人 开字母
```

开字符：

```text
@机器人 开 A
@机器人 开 7
@机器人 开 少
```

@机器人 后英文字母和数字可以省略空格（如 `@机器人 开A`、`@机器人 开7`）；中文 / 日文等文字字符需要保留空格（如 `@机器人 开 少`），以避免误识别。

每次有效开字符后，回复末尾会按首次开启顺序显示本局已经开启的字符；英文字母忽略大小写，重复开启不会重复记录。本局曲名中不存在的有效字符也会记录：

```text
开字母历史：
I O A
```

猜歌：

```text
@机器人 3 Credits
@机器人 1. Credits
@机器人 曲 3 Credits
```

编号和曲名之间用空格、`.` 或 `、` 分隔都可以。

结束：

```text
@机器人 结束开字母
@机器人 结束游戏
```

AstrBot 自身的 `/` 开头指令始终交给 AstrBot 处理，不受插件影响，例如：

```text
@机器人 /help
@机器人 /plugin
```

`@机器人 /xxx` 不会进入游戏逻辑。

### 默认模式（exclusive_mode=false）

插件只处理 @机器人 且明确属于开字母游戏的消息：`@机器人 开字母` 随时可触发；开字符（如 `@机器人 开 A`）、猜歌（如 `@机器人 3 Credits`）和结束（如 `@机器人 结束游戏`）只在本群有进行中的游戏时处理。

没有进行中的游戏时，上述快捷格式以及其他 @机器人 但无法识别的消息都不会被本插件拦截，会正常交给 AstrBot 的其他插件或 AI 对话处理，适合大多数公开 Bot。

### 独占模式（exclusive_mode=true）

开启后，@机器人 但无法识别为游戏指令的消息会由本插件接管：返回玩法提示，并停止事件传播，不进入 LLM。未 @机器人 的消息本插件完全不处理，`@机器人 /xxx` 等 AstrBot 指令仍会放行。

适合只用于开字母游戏的专用 Bot。默认关闭，可在 AstrBot WebUI 的插件配置中开启。

## 曲名隐藏规则

Unicode 字母和 ASCII 数字 0-9 使用 `•` 隐藏：

```text
Credits
•••••••

World Vanquisher
••••• ••••••••••

少女A
•••
```

规则：

- 所有 Unicode 字母（英文字母、中文汉字、日文假名等）都参与隐藏，可通过 `@机器人 开 少` 等方式开启
- 英文字母大小写视为同一字符
- ASCII 数字 0-9 默认隐藏，也可通过 `@机器人 开 7` 等方式开启；非 ASCII 数字（如全角 `９`）不隐藏，直接显示
- 空格直接显示
- 标点和符号直接显示
- 已猜中的歌曲显示完整原标题

## 答案匹配规则

- Unicode NFKC 规范化，全角与半角对应字符视为相同（如 `（Song）` 与 `(Song)`）
- 英文字母忽略大小写
- 猜歌时忽略任意位置的所有 Unicode 空白，包括半角 / 全角空格、连续空格和 Tab
- 弯引号（’ ‘ “ ”）与直引号视为相同，兼容手机输入法自动转换
- 其余标点必须正确
- 当前不支持别名
- 当前不支持错别字、编辑距离等其他模糊匹配

## 曲库

插件内置曲库位于安装目录的 `songs/` 目录，每个 txt 文件是一份独立曲库。代码通过固定映射识别以下曲库，不会扫描目录：

```text
songs/
├── phigros.txt
├── arcaea.txt
├── musedash.txt
├── maimai.txt
├── cytus.txt
├── cytus2.txt
├── deemo.txt
├── djmax.txt
├── lanota.txt
├── rotaeno.txt
├── chunithm.txt
├── soundvoltex.txt
├── pjsekai.txt
├── adofai.txt
└── beatsaber.txt
```

文件格式：

- UTF-8 编码（兼容 BOM）
- 一行一首歌曲，保留原语言标题，不翻译
- 空行自动忽略
- 仅加载代码中硬编码的内置文件路径；额外放入 `songs/` 的文件不会被识别

加载规则：

- 标题中至少包含一个 ASCII 英文字母（A-Z / a-z）或数字（0-9）的曲目才会进入曲池；纯中文、纯日文、仅全角数字等标题自动过滤
- 单个曲库文件内完全相同的重复行自动去重
- 多个曲库同时启用时，跨曲库重复歌曲在加载时按基础规范化口径去重（NFKC、忽略大小写、弯直引号等价、忽略首尾空白并折叠连续空白）；猜歌时允许增删空格的宽松规则不用于曲库去重，曲库文件本身不会被修改
- 合并后的曲池至少需要 8 首歌曲才能开始游戏

收录口径：

- 标题中参与遮罩的字符仅限 ASCII 字母 / 数字与 CJK 汉字。含日文假名（含长音符 `ー`、叠字 `々`）、谚文、希腊 / 西里尔字母、带变音符拉丁字母（如 `é`、`ü`）、全角字母等键盘不便输入字符的曲目不收录：此类字符答题时必须逐字精确输入，常规输入法无法输入，玩家实际无法作答。
- 直接显示的字符答题时同样需要逐字精确输入：含常规输入法打不出同款或形近不等价字符（如 `・`——中文键盘只能打出 `·`、`♯`——易误打成 `#`，以及 `♭ † 〚〛 ∅ ∀ °` 等）的曲目不收录。
- `☆ ★ ♪ ♥` 及箭头、几何图形等符号面板可选出的装饰符号，和中文标点、ASCII 标点、空格一样允许保留。

启用哪些曲库在 AstrBot WebUI 的插件配置中勾选（见「配置」），默认启用 Phigros、Arcaea、Muse Dash、maimai。

曲库随本仓库一起维护：通过插件市场或 Git 更新插件即可获得最新曲库。

## 游戏状态

游戏状态只保存在 AstrBot 进程内存中：

```text
group_id -> GameState
```

因此：

- 不同 QQ 群互不影响
- AstrBot 重启、插件重载或插件停用后，正在进行的游戏会丢失

这是当前版本的有意设计，不需要数据库。

## 配置

插件目前有两个配置项，可在 AstrBot WebUI 的插件配置页面修改：

- `exclusive_mode`（独占模式，默认 `false`）：开启后，@机器人 但无法识别的消息会返回玩法提示并停止事件传播，不再进入 LLM 或其他插件；未 @机器人 的消息本插件完全不处理。适合仅用于开字母游戏的专用 Bot。普通公开 Bot 推荐保持默认关闭。

- `enabled_libraries`（启用曲库，默认 `["phigros", "arcaea", "musedash", "maimai"]`）：勾选启用插件内置曲库，WebUI 中渲染为固定的复选框列表。可用曲库及文件位置由代码硬编码，不扫描 `songs/` 目录；配置中的未知曲库标识会被忽略。清空全部勾选等于关闭所有曲库，游戏将无法开始（不会自动恢复默认）。修改后需重载插件生效（在面板中保存会自动热重载）。
